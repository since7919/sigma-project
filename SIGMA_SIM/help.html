SIGMA 시뮬레이터 매뉴얼 (도움말)

1. 특수기능 예약 처리 방법 (시차계획 설정)

경찰청 교통신호기 설치운영 업무편람(3.2.1.2.4)의 특수기능 예약 처리 규격에 따라, 현시계획(Signal Map)의 시차계획을 특정 시간 및 조건에 맞춰 예약 운영할 수 있습니다.

예약 운영 조건 설정 기준

조건 설정 상태 제어 수행 방식
날짜(월/일) 설정 O, 요일 '0' (무관) 요일에 관계없이 지정된 해당 날짜의 시간에 제어 수행
날짜(월/일) 설정 X, 요일 '0' (무관) 해당 시간대에 매일 무조건 수행
날짜(월/일) 설정 X, 요일 지정 O 날짜에 상관없이 해당 요일의 시간에 제어 수행
날짜(월/일) 설정 O, 요일 지정 O 해당 날짜와 요일이 모두 일치하는 날의 시간에 제어 수행

입력 항목 설명

  • 월 (Month): 1 ~ 12 (빈칸 또는 0 입력 시 매월 적용)
  • 일 (Day): 1 ~ 31 (빈칸 또는 0 입력 시 매일 적용)
  • 요일 (Day of Week): 0 (무관), 1 (일요일) ~ 7 (토요일) 순으로 지정
  • 시간 (Time): 0~23시, 0~59분 형태로 시작/종료 시간을 지정합니다.
* 시뮬레이터는 기본적으로 6개의 시그널맵(일반, 시차1~시차5)을 보관하여 스케줄을 처리합니다.
* 예약 제어 조건에 부합하는 시차계획이 여러 개일 경우, 설정된 인덱스 순서에 따라 활성화됩니다.
