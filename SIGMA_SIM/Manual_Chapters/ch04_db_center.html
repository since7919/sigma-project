🗄️ Ch 04. DB CENTER (데이터 체계)

4. DB CENTER (8대 데이터 파일 아키텍처)

SIGMA의 모든 지능형 기능은 아래 8가지 핵심 CSV 파일의 유기적인 결합을 통해 작동합니다.

4.1 8대 핵심 데이터 파일 정의

1. db_intersections.csv

교차로 마스터: 위치(위경도), 명칭, 신호 맵 슬롯(0~7), 기하구조 인덱스 등 교차로의 정적 정보를 관리합니다.

2. db_links.csv

네트워크 마스터: 교차로 간 연결 관계(Up/Down Node), 실거리 보정값(KAP) 등 연동 분석의 기초가 되는 링크 정보를 저장합니다.

3. db_tod_plans.csv

일계획 상세: 각 계획 번호별 시작 시간, 적용 주기, 오프셋, 사용할 맵 번호 등 시간대별 신호 운영 안을 정의합니다.

4. db_weekly_plans.csv

주간 스케줄: 월요일부터 일요일까지 각 요일에 어떤 일계획(1~10번)을 적용할지 결정하는 상위 스케줄링 파일입니다.

5. db_special_days.csv

특수일 관리: 공휴일이나 지역 행사 등 특정 날짜에 우선적으로 적용할 예외 신호 계획을 관리합니다.

6. db_civil_complaints.csv

민원 이력: 시민들이 제기한 불편 사항의 유형, 위치, 발생 일시를 기록하여 YEARBOOK 점수에 반영합니다.

7. db_improvements.csv

시설 개선 데이터: LPI 설치, 감응제어 도입 등 물리적인 시설 개선 내역을 관리하여 운영 성과를 측정합니다.

8. db_volume_stats.csv

교통량 통계: 방향별 교통량(Volume), 포화도(V/C), 지체 시간 데이터를 저장하여 시뮬레이션의 정확도를 높입니다.

4.2 파일 간 참조 관계 (Relationship)

SIGMA의 데이터는 itstId (교차로 ID)를 중심으로 모든 파일이 유기적으로 연결되어 있습니다.

[Intersections] ↔ [TOD Plans] ↔ [Weekly Plans]
↑ (itstId) ↓
[Links] ↔ [Complaints] ↔ [Improvements]

4.3 TOD 스케줄 필드 상세 정의

필드명 (Header) 타입 상세 용도 및 비즈니스 로직
planIdInteger일계획 번호 (1~10). 특정 요일에 할당되는 단위 계획입니다.
startTimeTime신호 계획이 시작되는 시간 (HH:mm).
cyc, offInteger해당 시간대에 적용될 주기(Cycle)와 오프셋(Offset) 값입니다.
mapIdInteger교차로 마스터의 SignalMap 0~7 중 어떤 맵을 사용할지 결정합니다.

4.4 신호 시뮬레이터의 기본 기능 및 데이터 연결 메커니즘 (Data Pipeline)

시뮬레이터는 통합 DB의 정적/동적 데이터를 바탕으로 시간계획(TOD) → 일계획(Day Plan) → 시그널맵(Signal Map) → 등화 연산(calc) → 화면 표출(Rendering)의 5단계 파이프라인을 통해 방향별 화살표와 신호등에 실시간 녹색불을 켜주는 핵심 엔진입니다.

🔗 5단계 실시간 제어 파이프라인

  1. 1단계: 시간계획 (TOD Schedule / schedules): 시뮬레이터 현재 시각(t)이 속한 시간대 슬롯을 탐색하여 운영할 플랜 번호(pIdx)를 결정합니다.
  2. 2단계: 일계획 (Day Plan / dayPlans): 주간계획 및 요일(평일/토/일)에 따라 해당 플랜의 현시별 스플릿 초수(splitA, splitB)와 총 주기(Cycle)를 산출합니다. (※ 주말 계획이 비어있는 경우 자동으로 1번 기본 일계획으로 우회).
  3. 3단계: 시그널맵 (Signal Map / signalMaps): 각 현시 진행 시 점등될 방향별 이동류 번호(movA, movB), 보행 신호(pedMov), 황색 및 전적색 시간을 매핑합니다. (※ 맵 데이터가 불완전하거나 결측된 경우 0번 기본 일반맵으로 자동 안전 폴백).
  4. 4단계: 시뮬레이션 연산 엔진 (calc / simulation.js): 주기 내 경과 시간(pos = t % Cycle)을 계산하여 현재 현시에 해당하는 이동류에 녹색('G') 또는 황색('Y') 신호를 부여하고 잔여 시간을 산출합니다.
  5. 5단계: 그래픽 표출 및 DOM 제어 (junction_map.js): 모든 차량 이동류와 보행자 신호(pedSet)를 식별하여 지도 상의 SVG 화살표 및 신호등 DOM 색상을 실시간 녹색(#10b981)으로 전환합니다.

🛡️ 빈 일계획 자동 우회 (Plan Fallback)

주말/공휴일(Day 2~5) 일계획이 비어있거나 스플릿 합산이 0초인 경우, 신호 소등을 원천 방지하기 위해 1번 평일 기본 일계획(Day 1)으로 자동 우회하여 시뮬레이션을 중단 없이 유지합니다.

🛡️ 불완전 시그널맵 안전 폴백 (Map Fallback)

시차맵(1~4번)에 1현시만 정의되어 있거나(세종대로사거리 케이스 등) 황색시간이 누락된 경우, 자동으로 0번 표준 일반 시그널맵으로 우회하고 결측 현시 이동류를 기본 맵에서 계승하여 적색 고착을 차단합니다.
