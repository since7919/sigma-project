5. NODE/LINK 분석 (공간 네트워크 아키텍처)

SIGMA는 교차로(Node) 간의 물리적 거리를 계산하고 방향성을 분석하여 교통 네트워크(Link)를 자동으로 구축합니다.

5.1 ARN (Angular Relative Network) 알고리즘

- 위경도 좌표 기반 상대 각도 분석
- 8개 방향 섹터(Binning) 분류
- 최단 경로 및 동일 축 노드 자동 연결

5.2 Haversine 거리 계산 공식

Distance = R * c (R = 6,371,000m)

5.4 노드(Node) 편집 및 관리 기능

지도 인터페이스를 통해 교차로의 위치와 속성을 직관적으로 제어할 수 있습니다.

📍 노드 생성 및 이동

  • 노드 추가 (Add): 지도를 우클릭하거나 상단 '노드 추가' 버튼 활성 후 클릭 시 새로운 교차로가 생성됩니다.
  • 위치 이동 (Move): 노드 마커를 드래그하여 실제 도로 위치로 정밀하게 이동시킬 수 있습니다.

❌ 삭제 및 속성 수정

  • 노드 삭제 (Delete): 선택된 노드를 삭제하며, 연결된 모든 링크도 자동으로 제거됩니다.
  • 이름 변경 (Rename): 편집기 상단에서 명칭을 수정하면 지도와 DB에 즉시 반영됩니다.

5.5 링크(Link) 수동 편집 및 정밀 최적화

자동 구축된 네트워크 외에도 사용자가 직접 연동 축을 정의하고 거리를 보정할 수 있습니다.

🔗 링크 인터랙션 가이드

  1. 수동 연결 (Connect): '링크 모드'에서 출발 노드와 도착 노드를 순서대로 클릭하여 강제로 연동 축을 생성합니다.
  2. 즉시 삭제 (Quick Delete): Alt + 마우스 왼쪽 클릭으로 형성된 링크를 즉시 제거할 수 있습니다. (가장 빠른 편집 방식)
  3. 실거리 보정 (Distance Correction): 지도상의 직선거리와 실제 주행 거리가 다를 경우, 링크 속성에서 보정 계수(KAP)를 입력하여 TSD 정밀도를 높입니다.

5.7 연동그룹(Coordination Group) 구축 및 분석

개별 링크를 넘어, 주요 간선도로 전체를 하나의 연동 축으로 묶어 관리하는 고급 기능입니다.

📂 연동그룹 생성 워크플로우

  1. 노드 일괄 선택: Shift + 마우스 드래그 또는 개별 클릭으로 연동하려는 교차로들을 다중 선택합니다.
  2. 그룹 지정 (Grouping): 우측 패널의 '그룹 생성' 버튼을 클릭하여 선택된 노드들을 하나의 ID로 묶습니다.
  3. 주축(Main Axis) 정의: 그룹 내 첫 노드와 끝 노드를 기준으로 연동의 방향성(예: 동서축)을 설정합니다.
  4. 그룹 링크 자동 렌더링: 그룹화가 완료되면 지도상에 강조된 굵은 실선으로 그룹 링크가 그려집니다.

5.8 그룹 링크의 특성 및 TSD 동기화

연동그룹으로 묶인 링크들은 일반 링크와 차별화된 물리적/시각적 특성을 가집니다.

  • 시각적 강조: 그룹 링크는 일반 링크보다 2배 굵게 표현되며, 연동 효율(Bandwidth) 상태에 따라 동적으로 색상이 변합니다.
  • TSD 자동 정렬: 그룹을 선택하고 TSD를 실행하면, 그룹 내 노드들이 물리적 거리에 따라 최적 순서로 자동 배치됩니다.
  • 거리 자동 합산: 그룹 내 모든 링크의 거리가 합산되어 전체 구간의 평균 주행 속도와 통과 시간을 계산합니다.
💡 운영 팁: 복잡한 도심망에서 '연동그룹' 기능을 사용하면 수십 개의 교차로를 단 한 번의 클릭으로 TSD에 올릴 수 있어 분석 시간을 90% 이상 단축할 수 있습니다.
