서울 Tdata의 API 규격상 다음과 같이 나뉩니다:

10119 (v2xSignalPhaseInformation): SPaT (실시간 신호 정보) - 현재 직진/좌회전/보행자 신호등이 무슨 색인지, 남은 시간이 얼마인지 실시간으로 알려주는 데이터입니다.
10120 (v2xCrossroadMapInformation): MAP (교차로 정적 맵 정보) - 교차로의 위도/경도, 차로 수, 제한속도 등의 정적인 구조를 알려주는 데이터입니다.
우리가 아까 CSV 파일로 목록을 교체했던 파일 이름(v2xCrossroadMapInformation_...)이 바로 10120(MAP) 데이터입니다! 그리고 현재 seoul_spat_mock.json에 저장해 두고 app.js에서 불러오고 있는 데이터가 **10119(SPaT 실시간 신호 데이터)**입니다.

즉, 이미 10119에서 수신된 실시간 방향별 신호 상태 데이터를 보여줄 수 있도록 모든 로직이 완성되어 적용되어 있는 상태입니다.
